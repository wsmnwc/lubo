# B站直播间监控录屏助手

本项目包含两个版本的实现：

| 版本 | 技术栈 | 特点 |
|------|--------|------|
| **浏览器扩展版** | HTML/CSS/JavaScript | ✅ **推荐**，纯前端，无依赖，Chrome/Edge直接使用 |
| Python桌面版 | Python + tkinter + FFmpeg | 功能更完善，但需要安装环境 |

---

## 👉 推荐使用：浏览器扩展版

### 特点

- ✅ **零依赖**：无需安装Python、FFmpeg或任何第三方软件
- ✅ **纯前端**：使用HTML/CSS/JavaScript原生技术
- ✅ **开箱即用**：Chrome/Edge浏览器直接加载使用
- ✅ **后台运行**：浏览器后台运行即可，无需一直盯着页面

### 功能

| 功能 | 说明 |
|------|------|
| **直播间监控** | 支持输入主播直播间ID/链接，后台静默轮询检测开播状态 |
| **开播提醒** | 主播开播时，自动触发浏览器桌面弹窗通知 + 提示音 |
| **全自动录屏** | 检测到开播自动打开页面，授权后启动录制；下播自动停止并下载 |
| **基础管理** | 支持添加/删除监控主播、查看录屏历史、配置各项参数 |

## 快速安装（浏览器扩展）

### 步骤一：准备扩展文件

确保 `extension` 文件夹完整包含以下文件：

```
extension/
├── manifest.json      # 扩展配置
├── background.js      # 后台脚本
├── popup.html         # 弹出界面
├── popup.css          # 界面样式
├── popup.js           # 交互逻辑
├── content.js         # 内容脚本
└── offscreen.html     # 离屏页面
```

### 步骤二：安装扩展

#### Chrome 浏览器

1. 打开 Chrome，地址栏输入：`chrome://extensions/`
2. 右上角开启 **"开发者模式"**
3. 点击 **"加载已解压的扩展程序"**
4. 选择 `extension` 文件夹
5. 安装完成！

#### Edge 浏览器

1. 打开 Edge，地址栏输入：`edge://extensions/`
2. 左下角开启 **"开发人员模式"**
3. 点击 **"加载解压缩的扩展"**
4. 选择 `extension` 文件夹
5. 安装完成！

### 步骤三：开始使用

1. 点击浏览器工具栏中的扩展图标
2. 在 **"直播监控"** 标签页添加主播（支持ID或链接）
3. **双击** 主播项开启监控
4. 点击 **"开始监控"** 启动后台监控

## 详细使用说明

### 录制功能说明

由于浏览器安全策略限制，录制需要用户授权：

1. **检测到开播**：扩展自动打开直播间页面
2. **请求授权**：页面显示录制控制面板
3. **用户操作**：点击 **"🔴 授权录制"** 按钮
4. **选择内容**：在弹出的对话框中：
   - 选择要录制的 **标签页**
   - 勾选 **"分享音频"**（重要！）
   - 点击 **"分享"**
5. **自动录制**：授权后自动开始录制
6. **自动停止**：检测到下播自动停止并下载

> 💡 视频会自动下载到浏览器默认下载目录。

### 配置选项

在 **"设置"** 标签页可以配置：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 轮询间隔 | 10秒 | 检测直播间状态的间隔 |
| 视频格式 | WebM | 录制视频格式 |
| 桌面通知 | 开启 | 开播时显示通知 |
| 提示音 | 开启 | 开播时播放提示音 |
| 自动录屏 | 开启 | 开播后自动尝试录制 |

## 常见问题

### Q: 为什么需要手动授权录制？

**A:** 这是浏览器的安全策略。屏幕录制 API 必须由用户手势触发，防止恶意扩展在用户不知情的情况下录制屏幕。这是保护用户隐私的必要措施。

### Q: 录制的视频没有声音？

**A:** 请确保在授权时：
1. 选择了正确的 **标签页**（而不是整个屏幕）
2. 勾选了 **"分享音频"** 选项

### Q: 关闭浏览器后还能监控吗？

**A:** 不能。扩展依赖浏览器运行。建议让浏览器在后台运行（最小化即可）。

### Q: 可以同时监控多个主播吗？

**A:** 可以同时监控多个主播的开播状态。但同一时间只能录制一个主播。

### Q: 视频保存在哪里？

**A:** 保存在浏览器的默认下载目录。可以在浏览器设置中修改下载位置。

## 两个版本对比

| 特性 | 浏览器扩展版 | Python桌面版 |
|------|-------------|--------------|
| 安装难度 | ⭐ 简单 | ⭐⭐ 需要配置环境 |
| 依赖 | ❌ 无依赖 | ✅ 需要 Python + FFmpeg |
| 录制自动化 | ⭐⭐ 需要用户授权 | ⭐⭐⭐ 完全自动 |
| 画质 | 浏览器决定 | 原画下载（无损） |
| 平台限制 | Chrome/Edge | Windows |
| 后台运行 | 浏览器后台 | 系统后台 |

**推荐：** 如果只需要基本功能，选择 **浏览器扩展版**（零依赖、安装简单）。如果需要完全自动化的高清录制，选择 **Python桌面版**。
