# lubo

高保真原型已生成在 `index.html` 与 `pages/` 目录中：

- `index.html`：主入口，使用 iframe 平铺展示所有页面
- `pages/home.html`：产品概览 / 用户体验分析
- `pages/single-detect.html`：单样本检测（图文 + OCR + 算法选择 + 可解释性）
- `pages/batch-detect.html`：批量检测（CSV/JSON 上传 + 风险分层）
- `pages/model-setup.html`：模型权重管理与运行环境

打开方式：直接用浏览器打开 `index.html` 即可查看全部原型。
