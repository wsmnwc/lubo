# B站直播间监控录屏助手 - 浏览器扩展

一款纯浏览器扩展，专为哔哩哔哩（B站）直播间设计，实现24小时后台监控、开播自动提醒、直播间自动录屏全功能。

## 功能特性

### 核心功能

| 功能 | 说明 |
|------|------|
| **直播间监控** | 支持输入主播直播间ID/链接，后台静默轮询检测开播状态，可自定义轮询间隔 |
| **开播提醒** | 主播开播时，自动触发浏览器桌面弹窗通知 + 提示音 |
| **全自动录屏** | 检测到开播 → 自动打开直播间页面 → 点击授权后启动录制；检测到下播 → 自动停止录制并下载视频 |
| **基础配置** | 支持添加/删除监控主播、自定义录屏画质、视频保存格式、开关提醒/自动录屏 |

### 技术特点

- **纯浏览器扩展**：Chrome/Edge直接加载使用，**不依赖任何本地软件**（无Python、无FFmpeg、无第三方库）
- **纯前端实现**：使用HTML/CSS/JavaScript原生技术，开箱即用
- **后台运行**：保持浏览器后台运行即可，无需一直盯着页面
- **Manifest V3**：采用最新的Chrome扩展规范

## 文件结构

```
extension/
├── manifest.json      # 扩展配置文件（Manifest V3）
├── background.js      # 后台服务脚本（Service Worker）
├── popup.html         # 弹出界面HTML
├── popup.css          # 弹出界面样式
├── popup.js           # 弹出界面交互逻辑
├── content.js         # 内容脚本（注入直播间页面，控制录制）
└── offscreen.html     # 离屏页面（用于播放提示音）
```

## 安装教程

### 步骤一：下载扩展文件

确保扩展文件完整保存在一个文件夹中，例如 `B站直播间监控助手`。

### 步骤二：打开扩展管理页面

#### Chrome浏览器
1. 打开Chrome浏览器
2. 在地址栏输入：`chrome://extensions/` 并回车
3. 或者点击右上角菜单 → 扩展 → 管理扩展

#### Edge浏览器
1. 打开Edge浏览器
2. 在地址栏输入：`edge://extensions/` 并回车
3. 或者点击右上角菜单 → 扩展 → 管理扩展

### 步骤三：开启开发者模式

在扩展管理页面右上角，找到 **"开发者模式"** 开关，点击开启。

Chrome：

### 步骤四：加载已解压的扩展

1. 点击页面上的 **"加载已解压的扩展程序"** 按钮（Chrome）或 **"加载解压缩的扩展"**（Edge）
2. 在弹出的文件夹选择对话框中，选择扩展所在的文件夹
3. 点击 **"选择文件夹"**

### 步骤五：确认安装成功

扩展列表中会出现 **"B站直播间监控录屏助手"**，说明安装成功！

> 💡 建议将扩展固定到工具栏：点击工具栏右侧的扩展图标（拼图形状），找到本扩展，点击右侧的图钉图标。

## 使用教程

### 首次使用配置

#### 1. 打开扩展弹出界面

点击浏览器工具栏中的扩展图标，打开弹出界面。

#### 2. 添加监控主播

在 **"直播监控"** 标签页中：

1. 在输入框中输入以下任意一种格式：
   - **纯数字ID**：例如 `123456`
   - **直播间链接**：例如 `https://live.bilibili.com/123456`
   - **主播主页链接**：例如 `https://space.bilibili.com/123456`

2. 点击 **"添加"** 按钮

3. 系统会自动获取直播间信息，添加到列表中

#### 3. 开启主播监控

在主播列表中：

- **双击** 主播项可以快速开启/关闭该主播的监控
- 或者点击 **"开启监控"** 按钮

> 注意：至少需要开启一个主播的监控才能启动全局监控。

#### 4. 启动全局监控

点击 **"开始监控"** 按钮，启动后台监控。

此时：
- 扩展会按照设定的间隔轮询检测主播状态
- 即使关闭弹出界面，监控也会在后台继续运行

### 录制功能说明

#### 录制流程

当检测到主播开播时：

1. **自动打开直播间页面**：扩展会在新标签页中自动打开该直播间
2. **请求录制权限**：页面右上角会出现录制控制面板
3. **用户授权**：需要用户点击 **"🔴 授权录制"** 按钮（浏览器安全策略要求）
4. **选择录制内容**：在弹出的对话框中：
   - 建议选择 **"标签页"** 或 **"窗口"**
   - 勾选 **"分享音频"**（非常重要，否则没有声音）
   - 点击 **"分享"** 按钮
5. **自动开始录制**：授权后自动开始录制
6. **检测下播自动停止**：检测到主播下播后自动停止录制
7. **自动下载视频**：录制的视频自动下载到浏览器默认下载目录

#### 关于录制授权

由于浏览器安全策略的限制，**录制操作必须由用户交互触发**。因此：

- 首次录制时，需要用户手动点击授权按钮
- 浏览器会弹出"分享您的屏幕"对话框
- 选择正确的标签页并勾选"分享音频"

> 💡 建议：录制时保持直播间标签页打开，不要最小化到其他桌面。

#### 录制质量设置

在 **"设置"** 标签页中可以配置：

| 设置项 | 说明 |
|--------|------|
| 视频画质 | 原画、蓝光8M、蓝光4M、超清、高清、流畅（注：实际录制质量由浏览器决定） |
| 视频格式 | WebM（默认）、MP4 |
| 自动录屏 | 开启后，检测到开播自动尝试录制 |

## 常见问题

### Q1: 为什么需要手动授权录制？

**A:** 这是浏览器的安全策略限制。`getDisplayMedia` API（屏幕录制）必须由用户手势触发（如点击按钮），无法完全自动化。这是为了防止恶意扩展在用户不知情的情况下录制屏幕。

### Q2: 录制的视频没有声音？

**A:** 请确保在授权录制时：
1. 选择了正确的标签页
2. 勾选了 **"分享音频"** 选项
3. 如果选择"整个屏幕"，可能无法录制系统音频

### Q3: 视频保存在哪里？

**A:** 录制的视频会自动下载到浏览器的默认下载目录：
- Chrome: 设置 → 下载内容
- Edge: 设置 → 下载

> 也可以在浏览器的下载历史中找到并打开。

### Q4: 关闭浏览器后监控还会继续吗？

**A:** 不会。浏览器扩展依赖浏览器运行。如果关闭浏览器，监控也会停止。

> 💡 建议：让浏览器在后台运行（最小化即可），不要关闭。

### Q5: 可以同时监控多个主播吗？

**A:** 可以添加和监控多个主播的状态。但是**同一时间只能录制一个主播**（受限于浏览器录制机制）。

### Q6: 为什么检测不到主播开播？

**A:** 可能的原因：
1. 直播间ID输入错误
2. 网络问题导致API请求失败
3. B站API限制或限流

> 建议：检查网络连接，确认直播间ID正确。

### Q7: 录制的视频格式是WebM，如何转换为MP4？

**A:** WebM是现代浏览器推荐的格式，大多数播放器都支持。如果需要MP4格式：
- 可以使用在线转换工具
- 或使用格式工厂、HandBrake等视频转换软件

### Q8: 扩展会收集我的数据吗？

**A:** 不会。本扩展：
- 所有数据都存储在浏览器本地
- 不会向任何第三方服务器发送数据
- 仅调用B站公开API获取直播间状态

## 技术说明

### 核心技术栈

| 技术 | 用途 |
|------|------|
| Manifest V3 | Chrome扩展最新规范 |
| Service Worker | 后台常驻，轮询监控 |
| chrome.storage | 本地数据存储 |
| chrome.notifications | 桌面通知 |
| chrome.downloads | 文件下载 |
| chrome.tabs | 标签页管理 |
| chrome.scripting | 脚本注入 |
| MediaRecorder | 视频录制 |
| getDisplayMedia | 屏幕/标签页捕获 |
